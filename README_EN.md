# Rabbit Launcher

A community rebrand of Hyper Launcher 3 for Minecraft: Java Edition on Android.

The original launcher engine, project structure, features, and dependencies are retained. This repository applies a conservative Rabbit Launcher identity while preserving upstream attribution and license terms.

## Build

```bash
./gradlew :Hyper_Launcher_v3:assembleDebug
```

On Windows, use `gradlew.bat`.
