# Rabbit Bridge v0.1

Create a ZIP named `Rabbit_Profile.zip` with these folders:

```text
Rabbit_Profile.zip
├── controls/   # compatible Rabbit control-layout JSON files
├── mods/       # .jar mods compatible with the selected instance
└── config/     # instance configuration files and subfolders
```

Import from the Rabbit Bridge card on the home screen. Choose a Minecraft instance first. Existing files are skipped; archive paths and extracted sizes are checked.

Mojo/Pojav control layouts are not all identical. v0.1 imports compatible JSON layouts but does not convert every third-party format automatically.
